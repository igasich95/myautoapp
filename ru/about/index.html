Что такое MyAuto

MyAuto — приложение для учёта расходов на авто и поездок для iPhone. Оно собирает в одном месте расходы на машину, заправки и зарядки, историю ТО, пробег и поездки и само считает цифры: расход топлива, стоимость километра или мили и стоимость владения

Чем MyAuto не является

Чтобы знать заранее, до установки

  • Не приложение для Android. MyAuto сделано для iPhone.
  • Отдельных версий для iPad, Mac и Apple Watch нет: MyAuto — приложение для iPhone.
  • Не приложение для CarPlay. Идущая поездка видна на экране CarPlay как «Эфир активности» с расстоянием и временем.
  • Не диагностический сканер. Через OBD-адаптер MyAuto только читает данные — пробег, топливо, давление в шинах — и не читает и не стирает коды ошибок.
  • Нет экспорта в CSV и импорта из других приложений. Данные переносятся резервной копией JSON или PDF-отчётом.
  • Нет рекламы, данные никогда не продаются.
  • Аккаунт не нужен. Вход с Apple — только для синхронизации через iCloud, профиля или рейтинга водителей.
