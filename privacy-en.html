Personal Data means any information relating directly or indirectly to an identified or identifiable individual (User).

Developer means Igor Alekseevich Zotov.

Personal Data Processing Terms

For the purposes of the Policy, Personal Data processing means collection, systematization, storage, clarification, retrieval, use, transfer, anonymization, blocking, and destruction of Personal Data.

The Developer does not perform the actions specified in clause 3.1 of the Policy with the User's Personal Data.

Data entered by the User in the Mobile Application is processed and stored locally on the User's device. This is necessary for the operation of the Mobile Application.

Data entered by the User in the Mobile Application is stored on the User's device.
